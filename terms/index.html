02

2. 適用範圍

本條款適用於：

  • joyfulnesspath.com及其活動子頁；
  • Joyfulness Path的免費及付費線上活動；
  • 報名、付款、確認電郵、Zoom參與及活動回放；
  • 由Joyfulness Path提供的文字、圖片、聲音、音樂、影片、練習及其他材料。

如個別活動頁載有特別條款，該等特別條款與本條款同時適用；如兩者直接衝突，以個別活動頁清楚列明的特別條款為準。

3. 參加資格

  1. 活動主要為年滿18歲人士而設。
  2. 未滿18歲人士須先取得父母或法定監護人同意，並按主辦方要求由相關人士協助完成報名。
  3. 主辦方可因活動性質、容量、安全或其他合理原因限制或拒絕個別報名。
04

4. 報名資料及帳戶安全

  1. 你須提供真確、完整及可聯絡的資料，並在資料有變時通知主辦方。
  2. 報名資格、確認電郵、Zoom連結、密碼及回放連結只供已登記人士使用，不得轉售、公開張貼或未經許可與他人共用。
  3. 如主辦方合理相信連結被濫用、帳戶資料不實或活動秩序受到影響，可取消或限制相關存取權。
  4. 因你提供錯誤電郵、垃圾郵件設定、裝置問題或未有按指示登入而無法參與，主辦方會在合理範圍內提供協助，但不保證可補回完整活動內容。
05

5. 個人選擇、身心安全及專業支援界線

  1. 活動內容只供個人成長、靈性探索、反思、創意體驗及一般資訊用途，不屬醫療、心理健康或其他受規管的專業服務，不具有醫療用途或效用，亦不構成診斷、治療、處方或專業意見。
  2. 活動不應取代醫生、心理健康專業人士、律師、財務顧問或其他合資格專業人士的意見或支援。如你正在接受相關專業支援，應繼續按照該專業人士的建議行事，不應單憑活動內容自行停止或更改既有支援、處方或用藥安排。
  3. 活動中有關能量、天使、牌卡、顯化、直覺、訊息或其他靈性概念，可按個人信念作象徵性或反思性理解。主辦方不聲稱其為可客觀驗證的事實，亦不保證任何超自然接觸、靈性覺醒、能量改變、財富、關係、未來事件或其他人生結果。
  4. 每位參加者的感受及所得均可能不同。任何分享、引導、牌卡解讀、提問或回應，都不應被理解為指示你作出特定人生、關係、財務、法律或其他重大決定。
  5. 參加者須保留自己的判斷及決定權，並自行考慮個人狀況。你可隨時暫停、不回答問題、關閉鏡頭、保持靜音或離開活動，毋須解釋。
  6. 如活動引起持續不安、混亂、難以承受的感受，或令你覺得自己或他人的安全可能受影響，應立即停止參與並尋求所在地合資格專業人士或適當支援；如涉及即時安全風險，請聯絡所在地的緊急服務。
  7. 主辦方可基於參加者、工作人員或現場安全，暫停某個環節或終止個別人士參與，但此安排不代表主辦方正在提供風險評估或專業服務。

  1. 活動可能透過Zoom、Facebook、YouTube或其他第三方平台進行。你使用相關平台時，亦受該平台本身的條款及私隱安排約束。
  2. 網絡、裝置、地區限制、平台維護、第三方服務中斷或其他非主辦方可合理控制的情況，可能影響直播、聲音、畫面、留言或回放。
  3. 主辦方會作合理準備及處理，但不保證第三方平台永久或全程無故障。
  4. 如發生重大技術問題，主辦方可按情況延遲、改期、更換平台、提供替代內容或採取其他合理安排。

7. 公開直播、Zoom參與及錄影

  1. 個別活動可能同時在Facebook、YouTube或其他公開平台直播。活動頁會說明相關安排。
  2. 除非事前另行取得你的明確同意，主辦方不會主動把你的姓名、影像、聲音或私人訊息公開播出。
  3. 公開直播部分原則上只顯示Winnie、主持人及已獲授權的嘉賓。Zoom參加者應預設保持靜音，並避免在顯示名稱或聊天室中披露不希望他人看見的資料。
  4. Zoom內的顯示名稱、發言及聊天室內容可能被同場參加者看見。參加者須自行控制其顯示名稱及分享內容。
  5. 如邀請個別參加者在公開部分出聲或出鏡，主辦方會另行取得明確授權；接受本一般條款本身不構成公開使用你聲音或影像的授權。
  6. 未經主辦方及相關人士同意，參加者不得錄音、錄影、截圖、複製、轉播或公開其他參加者的分享。
  7. 主辦方如需錄製活動作內部記錄、回放或日後發布，會在活動頁、報名流程或活動開始前說明適用範圍。

8. 參與守則

參加者須保持尊重，並不得：

  • 騷擾、侮辱、威脅或針對其他人士；
  • 發布違法、侵權、誤導或不適當內容；
  • 擅自收集、保存或分享其他參加者資料；
  • 干擾直播、Zoom、聊天室或網站運作；
  • 宣傳未經許可的產品、服務、群組或活動；
  • 冒充他人或繞過存取限制。

如有違反，主辦方可刪除內容、靜音、移除參加者、限制再次參與或採取其他合理措施。嚴重情況下可即時終止參與資格。

  3. 如個別付費頁沒有另行列明，默認安排為：參加者取消、個人時間衝突、裝置或網絡問題、未出席並不自動產生退款權；參加者如在活動開始前不少於48小時提出，主辦方可按名額及活動性質酌情允許一次改期或名額轉讓；此安排不減少依法不可排除的權利。

  6. 任何購買、改期或退款安排不影響參加者依法享有且不得排除的權利。
